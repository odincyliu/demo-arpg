# CC0 VFX 素材來源

本目錄只收錄實際用於遊戲的精選檔案。所有下列素材均由來源頁標示為
CC0 1.0；雖然不強制署名，仍保留作者、原始網址與下載檔雜湊，方便日後稽核。

原始像素內容維持不變。遊戲執行時由 `shadow_sprite.gdshader` 依亮度重映為
近黑本體、灰色細節與灰白輪廓；這項 Runtime 灰階處理不會覆寫來源圖檔。
